## 모델 구성
1. **단계 모델**: 피처 96개 → LightGBM 3개(seed 42/43/44) 확률 평균 → 45℃ 규칙 → 누적확률 디코딩 → 실험 내 단조 증가
   - 45℃ 규칙: EDA에서 `t1 누적 최댓값 >= 45℃ ⇔ 2단계 이상`이 train·validation 전체에서 성립. 미만이면 1단계, 이상이면 1단계 확률 0
   - 누적확률 디코딩: `P(단계 >= k)`가 임계를 넘는 경계 수로 단계를 정함
   - 단조 증가: 라벨이 모든 실험에서 1→6으로만 증가하므로, 같은 실험의 과거 예측보다 낮추지 않음(과거만 사용)
2. **2→3 전용 모델**: 피처 161개(센서 + 2단계 진입 후 경과 초 + 공간 핫스팟 + 프레임 간 변화) → 라벨 2·3 행만 학습한 이진 LightGBM 3개 평균. 2단계 진입 이후 처음 확률 0.5를 넘는 시점을 3단계 시작으로 사용
   - 적용 그룹: 280Ah, 6Ah 셀. 실험 단위 CV에서 2→3 경계 오차가 뚜렷이 줄어든 그룹(280Ah·가열 방식 2: 평균 31.0행 → 17.4행, 6Ah: 15.8행 → 13.0행). 다른 그룹은 단계 모델 예측 유지
3. **73Ah·가열 방식 2 그룹**: 3단계 시작 = 2단계 진입 시각 + Train 같은 그룹의 2단계 길이 중앙값(515초). 이 그룹은 2단계 길이가 짧은 군(90~135초)과 긴 군(440~615초)으로 갈리는데, 모델이 긴 군을 짧게 예측하는 오류가 반복되어 중앙값 규칙으로 대체

## 이미지 사용
- **흑백 통계의 실험 내 상대 변화**: 베이스라인 흑백 통계 5개에 대해 첫 프레임 대비, 지금까지 최솟값 대비, 30초 전 대비 변화. 프레임마다 색 범위가 자동 조정되는 이미지라 절대값은 실험 간 비교가 어렵고, test와의 분포 차이도 상대값이 더 작았음(실험 단위 adversarial validation AUC: 상대값 0.43, 절대값 0.59)
- **온도 지수 지도**: 컬러맵을 팔레트로 역변환해 0~1 온도 지수로 바꾸고 24×32로 축소
  - 공간 핫스팟: 프레임별 범위로 정규화한 고온 영역 면적·중심·퍼짐·경계 선명도·엔트로피·비대칭과 그 30/120초 변화
  - 프레임 간 변화: 첫 프레임·15/30/60초 전 프레임과의 공간 상관, 평균 절대 변화, 변한 픽셀 비율과 누적 최소·최대
- 빈 이미지(검정·흰색)를 넣으면 test 예측의 1.16%가 바뀜

## 학습·검증 구성
- 학습 데이터: Train split만 (Validation은 검증과 설계 선택에 사용)
- 검증 방법
  - 제공 Validation(19개 실험): Train만으로 학습 후 채점
  - 실험 단위 교차검증: train+validation 97개 실험, 5-fold × 3회 반복. test와 같은 조건(배터리 그룹)의 실험만 모은 점수도 함께 확인
- 검증 점수 (Macro F1)

  | 구성 | Validation | CV 전체 | CV test 조건 |
  |---|---|---|---|
  | 단계 모델만 | 0.8624 | — | — |
  | + 73Ah 규칙 | 0.8659 | 0.8838 | 0.9129 |
  | + 280·6Ah 2→3 전용 모델 (최종) | **0.8727** | **0.8865** | **0.9186** |

  최종 구성의 CV fold별 개선/악화: 14/1. 단, 2→3 전용 모델의 적용 그룹은 train+validation CV로 정했으므로 Validation 점수가 완전히 독립적인 평가는 아님

## 시계열 피처 구성
- 모든 시계열 피처는 같은 `experiment_id` 안에서 `relative_time_s <= 현재`인 관측만 사용
- 윈도우는 행 수가 아니라 초 단위 (test에 10초·15초 간격 실험이 있음): 15/30/60/120초 기울기·변화량
- 누적 최댓값·최솟값, 사건(t1 45/60/80/150/300℃ 도달, 전압 1V·0.1V 미만, 압력 상승) 이후 경과 초
- 미래 시점 관측, 실험 전체 기준 통계(전체 평균·최댓값·실험 길이)는 사용하지 않음
- 자체 점검(`test.py`로 실행): 행 순서 섞기, 실험 하나씩 따로 넣기, 실험마다 앞 60%만 넣기에서 예측 불일치 0%. 같은 입력 재실행 불일치 0%

## 전처리 기준
- 팔레트(`palette.npy`)는 train·validation 이미지의 색만으로 만듦(`build_palette.py`)
- 학습으로 구하는 값(73Ah 그룹 중앙값 515초 등)은 전부 Train에서 구해 `weights/`에 저장. `test.py`는 아무것도 fit 하지 않음
- 미리 계산한 피처 파일을 읽지 않음. `test.py`가 원본 이미지에서 직접 계산
